# 隐私与使用安全

- 在用户已选择的宿主会话中，按该宿主实际适用的数据处理和留存规则分析材料；不要求另行使用本地 LLM，也不因宿主本身重复确认。先说明宿主的数据处理边界，并只提供完成诊断所需的最少材料。不得擅自把材料转发到其他云服务、外部目标、公开仓库或社交平台；此类额外传输或公开分享须先获得明确授权。
- 原始材料和个人诊断数据存放在 Git 忽略目录或其他排除提交的本地位置；提交前核对暂存内容和示例，文件名不使用姓名或联系方式。项目脚本仅在本地处理输入，不联网传输。演示案例只用清楚标注的合成数据，不能伪装成真实用户或真实 JD 市场样本。
- 如果宿主的数据处理边界不适合用户提供的材料，说明限制并改用用户认可的最少化/脱敏材料或合成案例。不得自行查询个人身份、向额外服务上传材料或公开分享。
- 最小化留存：只保留完成分析所需的字段；报告引用使用材料 ID 和必要短摘述，不复制无关个人信息。用户要求删除其本地副本时，清理本次创建的个人文件和引用。
- 报告不保证面试结果、录用、涨薪或能力认证；不能替代招聘方核验、法律/心理/医疗等专业意见。
- 只使用合法、获准访问的招聘信息；避免绕过平台限制的大规模抓取。公开演示、发布案例或把客户报告用于宣传前，必须获得明确许可并完成脱敏。
